# Axante Autonomous Quality Gates

This repository is developed autonomously toward a verified flagship-quality website.

Canonical control-plane issues:
- `[AXANTE-NORTH-STAR] Awwwards benchmark & convergence contract`
- `[AXANTE-RELEASE-GATE] Latest hard QA`
- `[AXANTE-VISUAL-QA] Latest visual audit`
- `[AXANTE-BENCHMARK-LAB] Living benchmark matrix`
- `[AXANTE-SEARCH-AI-QA] Latest discoverability audit`
- exactly one open `[AXANTE-NEXT] ...` implementation issue

Priority order:
1. release blockers, including hard Search/AI blockers such as noindex/canonical/sitemap/crawl failures;
2. global/mobile regressions;
3. structural regression risk;
4. usability/conversion;
5. lowest verified page-quality floor;
6. critical Search/AI discoverability gap;
7. largest verified visual/benchmark gap;
8. interactive conversion / signature experience when maturity prerequisites are met;
9. new creative scope.

A green build is not a visual pass. A visual pass requires current pixel evidence. A flagship verdict requires current pixel evidence, a green release gate, direct benchmark comparison, per-page quality floors, Search/AI flagship status, and persistence across multiple verified cycles.

User-provided screenshots are first-class visual evidence and override automated assumptions when they show a real regression.

Averages may never hide a weak route. If quality plateaus, the system must change paradigm rather than repeatedly polish the same component. Benchmark references must remain live and verified rather than static.

## Search & AI Discoverability

SEO, GEO and AIO are handled as one evidence-based discoverability system rather than as separate collections of tricks.

The system must preserve and verify:
- crawlability and indexability;
- canonical correctness;
- sitemap completeness for all intended indexable routes;
- robots and preview-vs-production indexing safety;
- unique and intent-aligned title/meta content;
- semantic HTML and useful internal linking;
- truthful and appropriate structured data;
- clear Axante entity/brand signals;
- people-first, original, useful content with demonstrable first-hand proof;
- answerability/extractability for AI systems without depending on motion or hidden UI state;
- citation-worthiness through concrete examples, evidence and attributable claims;
- Core Web Vitals readiness and strong page experience.

Do not create keyword-stuffed pages, thin programmatic content, fake FAQs, invented KPI/pricing, or schema that claims information not present and verifiable on the page.

The canonical discoverability audit is `[AXANTE-SEARCH-AI-QA] Latest discoverability audit`.

`FLAGSHIP CANDIDATE` requires at least `SEARCH-AI READY`.
`FLAGSHIP` requires `SEARCH-AI FLAGSHIP` and no critical verified Search/AI area worse than the current axante.it production site.

## Interactive conversion

A configurator or gamified flow is not mandatory by itself. Once foundation, mobile, page floors and Search/AI quality are mature, the site should include a business-fit signature experience that improves understanding, qualification, memorability or conversion. The specific interaction model must be selected on evidence and must never outrank more serious blockers.
